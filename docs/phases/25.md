# Phase 25: Text attachments

[Implementation plan](../implementation-plan.md) · [Documentation index](../README.md)

The shared gateway processor supports UTF-8 `.txt`, `.md`, and `.markdown` attachments with durable
intake, structured source provenance, schema migration 4, and text-only provider
requests. PDF processing and local voice transcription have been removed.
Previously saved PDF text and voice transcripts remain readable; their schema
and existing tool restrictions are retained for saved records.

Automated checks cover intake, download/decoding limits, unsupported-type
rejection, migration rollback, restart/deduplication, URL authority, and context
overflow. No bundled adapter currently accepts attachments; live intake and model
grounding are unverified.
