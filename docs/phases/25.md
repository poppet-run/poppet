# Phase 25: Text attachments

[Implementation plan](../implementation-plan.md) · [Documentation index](../README.md)

Removed on 2026-10-24. The shared gateway processor accepted UTF-8 `.txt`, `.md`,
and `.markdown` attachments with durable intake and structured source provenance,
but no bundled adapter supplied attachments: Discord never set an incoming
attachment or implemented download, so the pipeline could not run. Live intake
and model grounding were never verified.

The gateway attachment processor, `gateway_attachments` table, channel download
operation, and attachment error reason are gone. Messages no longer carry a
`source`, and context assembly and conversation search no longer read attachment
text, previously saved PDF text, or voice transcripts. PDF processing and local
voice transcription had already been removed.

Attachments would need a new phase that starts from an adapter able to deliver
them. Git history retains the removed implementation.
