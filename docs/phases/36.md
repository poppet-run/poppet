# Phase 36: Reviewed MCP actions

[Implementation plan](../implementation-plan.md)

Give explicitly opted-in MCP tools the same review decisions as Bash. Keep
reviewed tools withdrawn after untrusted content or attachments enter the run.
Record review and dispatch separately so an interrupted review does not look
like an uncertain remote action.

1. Add interactive review, per-tool configuration, and the tool journal record.
2. Reuse the gateway's Discord and Slack controls for one-time approval.
3. Add a separate scheduled opt-in. A scheduled call that needs human approval
   fails its occurrence, with the reason visible in `tasks show`.

Use fake MCP servers and reviewer responses for dispatch and recovery tests.
Verify real provider effects and Discord and Slack approval separately.
