# Phase 5: Tool execution

[Implementation plan](../implementation-plan.md) · [Documentation index](../README.md)

The sequential tool loop validates whole batches before execution, bounds tool
results, and records requests and outcomes in the durable journal. Cancellation
and recovery preserve uncertainty without replaying calls. Automated tests cover
provider tool exchanges, permissions, budgets, and recovery.

Remaining live check: run a tool-capable chat and resume it using a real provider.
See [chat](../chat.md) and [storage](../storage.md#permissions-and-recovery).
