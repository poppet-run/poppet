# Poppet

A small personal AI agent for local use, built with TypeScript, Bun, and Effect.

Chat in the terminal, in a browser, or through Discord, Slack, and Telegram, with support for
ChatGPT, OpenCode, OpenCode Go, OpenRouter, and Gemini. Sessions are saved locally so you can pick up
past conversations.

Poppet can remember facts and use local Markdown skills. It can also read web pages, search the web, use explicitly
allowed local and HTTP MCP tools, and run scheduled tasks through a shared background worker.

## Documentation

Setup and user guides are at [poppet.run/docs](https://poppet.run/docs/). To work on
Poppet itself, start with the [engineering notes](docs/README.md).
