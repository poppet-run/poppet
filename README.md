# Poppet

A small personal AI agent for local use, built with TypeScript, Bun, and Effect.

Chat in the terminal or through Discord, with support for
ChatGPT, OpenCode Go, and OpenRouter. Sessions are saved locally so you can pick up
past conversations.

Poppet can remember facts and use local Markdown skills. It can also read web pages, search the web, use explicitly
allowed local and HTTP MCP tools, and run scheduled tasks through a shared background worker.
