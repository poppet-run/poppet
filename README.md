# Poppet

A small personal AI agent for local use, built with TypeScript, Bun, and Effect.

Chat in the terminal or through Discord, Telegram, and WhatsApp, with support for
ChatGPT, OpenCode Go, and OpenRouter. Sessions are saved locally so you can pick up
past conversations.

Poppet can work with notes, remember facts, and use selected project context and
local Markdown skills. It can also read web pages, search the web, use explicitly
allowed local MCP tools, and run scheduled tasks through a shared background worker.
